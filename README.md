# XA-LUXURY / 连单系统 本地复刻

用户端 UI 使用原站前端资源，后台按连单系统管理端复刻，接口跑在本地。

## 启动

```bash
cd luxury-clone
npm install
npm start
```

- 用户端：http://127.0.0.1:5173
- 后台：http://127.0.0.1:5173/admin/
